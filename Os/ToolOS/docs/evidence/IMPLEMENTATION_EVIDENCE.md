## Echo Discovery Parity Note
Echo discovery is functionally dependent on the regenerated `deepakllm/tools.json` metadata file (generated by Echo's `src/_toolspec.ts` script). ToolOS reads this file directly. 
Because ToolOS does not execute the generation step, the discovered tools reflect exactly the contents of `tools.json`, which may theoretically drift from `src/tools/registry.ts` if Echo developers forget to run `npm run toolspec`. 
This is documented as a known dependency limitation of a read-only integration.
